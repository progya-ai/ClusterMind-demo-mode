Public demo. Real Alibaba GPU cluster data, recorded. Here the AI model is replaced by a simple keyword parser, so the Ask tab is off. The answer checker and the safety guard are the real code. Run ClusterMind locally for the full app with local AI models.

System

How much does the checker help?

Each small AI model answered 320 test questions. Raw accuracy is how often it is right on its own. With the checker on, only answers that pass are delivered: answers delivered is how many get through, and delivered accuracy is how many of those are correct. (Source: results/e2_endtoend.json)

Cluster snapshot

Real node records from the Alibaba PAI trace. Green = busy, yellow = idle, red = recent failures. GPU util is relative to one GPU, so 200% means about two GPUs’ worth of work. Click a node to ask about it.
